# Brandly Full-Stack Starter (Flask)

This project combines a responsive landing page with a small Python Flask backend.

## Requirements
- Python 3.10+
- pip

## Run on Windows
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal in VS Code.
4. Create and activate a virtual environment:

   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   ```

5. Install packages:

   ```powershell
   pip install -r requirements.txt
   ```

6. Copy `.env.example` to `.env` if you want to adjust settings.
7. Start the backend:

   ```powershell
   python app.py
   ```

8. Open `http://127.0.0.1:5000`.

## API endpoints
- `GET /api/health` — checks whether the backend is running.
- `POST /api/chat` with JSON `{"message":"I need a landing page"}` — returns a demo chatbot reply.
- `POST /api/contact` with JSON `{"name":"Sam","email":"sam@example.com","message":"I need a landing page"}` — validates form input and returns a demo acknowledgement.

## Important limitations
- Chat replies are preset demo responses, not generated by a real AI model.
- Contact messages are not stored in a database or emailed yet.
- Before using this with real customers, add secure storage/email delivery, rate limiting, spam protection, and privacy information.
- For real AI, call your chosen AI provider from `app.py` using a server-side API key. Never put API keys in `static/script.js`.
